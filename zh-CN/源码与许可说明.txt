二、修改内容摘要
--------------------------------------------------------------------------------
相对于官方原版，本版本只做了以下改动，未改变任何功能逻辑：

1. 界面文案本地化
   · 修改文件：
       OptiScaler/menu/menu_common.cpp
       OptiScaler/dllmain.cpp
   · 把界面上的英文文案替换为简体中文，共约 1000 处字符串。
     所有占位符（{}、{0}、%%、##ID）和转义引号都保持原样。

2. 中文字体支持
   · 新增文件：OptiScaler/menu/font/NotoSansSC_Subset.h
     内嵌「思源黑体（Noto Sans SC）」子集，只包含界面实际用到的字形，
     以 C++ 静态字节数组形式编译进 DLL。
     字体授权：SIL Open Font License 1.1。
   · 修改文件：OptiScaler/menu/menu_common.cpp
     在字体图集里把中文字体以 Merge（合并）方式追加到原有字体之后，
     拉丁字符仍由原版 Hack 字体渲染，汉字由思源黑体渲染。
     另外，当配置里 UseHQFont=false 时，也会直接把该子集作为默认字体
     加载，避免 ImGui 退回只含 ASCII 的内置字体而导致中文变成方块。

3. 编译参数
   · 新增文件：Directory.Build.props
     为 MSVC 增加 /utf-8 开关，保证源码中的 UTF-8 中文被正确编译。

4. 配置注释汉化
   · 修改文件：OptiScaler.ini
     只翻译以「;」开头的注释行，键名与取值一律未改动。

5. 安装脚本提示汉化
   · 修改文件：setup_windows.bat、setup_linux.sh
     只翻译交互提示文字与注释，脚本逻辑完全未改动。
     setup_linux.sh 保持 LF 换行（若为 CRLF，Linux 下会报 bad interpreter），
     并已通过 bash -n 语法校验；批处理脚本保持 CRLF 换行，避免 cmd 解析异常。

6. 版本串标注汉化版
   · 修改文件：OptiScaler/resource.h
     在「展示用」的产品版本串后追加「 简体中文版」标识，叠加界面的窗口标题可见。
     数值版本号 10.0.0（VER_MAJOR/MINOR/HOTFIX_VERSION）以及 OPTI_VERSION 一律
     未改动——它们会被传给 DLSS / XeSS / FSR 的引擎注册接口，版本更新检查也依赖
     它们，改动可能影响第三方运行库，故只在给人看的版本串上加标识。

7. 文档说明
   · 修改文件：README.md
     在文件顶部追加简体中文的「下载方式 / 安装步骤 / 汉化清单 / 授权说明」一节，
     上游原始英文 README 的内容完整保留在下方，未作删除。

三、如何获取对应源码
--------------------------------------------------------------------------------
GPLv3 第 3 节要求分发二进制时提供「对应源码」。本汉化版的完整源码包含在
随附的源码压缩包中（文件名通常为 OptiScaler-CN-source.zip）。

源码压缩包内容 = 上述修改后的完整工程，可直接使用 Visual Studio + MSBuild
编译，命令为：
    msbuild /m /p:Configuration=Release OptiScaler.sln

如果源码包不慎丢失，也可以：
  · 从原始项目 https://github.com/OptiScaler/OptiScaler 获取官方源码；
  · 本汉化版的源码位于第三方维护者的同名仓库（OptiScaler-CN）。
